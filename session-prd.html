四、数据同步与远程指令

4.1 同步规则

内容类型是否同步说明
用户 Query✅ 必须同步纯文本/图片各端能展示
AI 文本回复✅ 必须同步Markdown 各端能渲染
文件产物⚠️ 元信息同步文件实体留本地，对端显示卡片+"传到本机"
思考过程❌ 不同步"思考完成"折叠块
任务状态✅ 实时同步进行中/已完成/失败

4.2 远程指令状态机

PENDING → DELIVERED → EXECUTING → SUCCESS / FAILED
                                    ↘ TIMEOUT（TTL 7天）
                                    ↘ CANCELLED

4.3 异常处理

场景处理用户感知
B 端离线入云端队列 TTL=7天"PC 离线，上线后自动执行"
B 端上线自动取出执行推送"PC 已开始执行"
执行中网络断B 端本地继续A 端"等待结果回传…"
并发冲突FIFO 排队"排队中（前面 1 个）"
Agent 崩溃30s 无心跳→FAILED"执行异常，请在 PC 检查"

五、超级岛与跨端通知

• 任务执行中 → 超级岛进度气泡
• 任务完成 → 系统通知，点击跳到 session 详情（不跳笔记）
• 跨端联动：手机发起任务 + 用户正在用 PC → PC 端也弹完成通知
• 首次远程指令 → 系统授权弹窗，之后同账号互信
