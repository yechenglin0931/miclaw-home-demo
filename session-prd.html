四、数据同步与远程指令

4.1 同步规则

内容类型同步说明
用户 Query✅ 必须纯文本/图片各端展示
AI 文本回复✅ 必须Markdown 各端渲染
文件产物⚠️ 元信息文件实体留本地，对端显示卡片+"传到本机"
思考过程❌"思考完成"折叠块
任务状态✅ 实时进行中/已完成/失败

4.2 远程指令状态机

PENDING → DELIVERED → EXECUTING → SUCCESS / FAILED
                                        ↘ TIMEOUT（7天）
                                        ↘ CANCELLED

4.3 异常处理

场景处理用户感知
B 端离线入队列 TTL=7天"PC 离线，上线后自动执行"
B 端上线自动执行推送"PC 已开始执行"
并发冲突FIFO 排队"排队中（前面 1 个）"
Agent 崩溃30s→FAILED"执行异常，请在 PC 检查"
用户取消cancel 信号"已取消"+部分结果保留

五、通知与授权

• 任务执行中 → 超级岛进度气泡
• 完成 → 系统通知，点击跳 session 详情（不跳笔记）
• 跨端联动：手机发起 + 用户正在用 PC → PC 也弹完成通知
• 首次远程指令 → 系统授权弹窗，之后同账号互信
• 无多台设备 → 空态引导（引导登录同账号）
• 删除操作同步所有端，文件保留在资料库
